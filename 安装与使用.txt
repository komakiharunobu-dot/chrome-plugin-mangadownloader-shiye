拾页 · 漫画图片下载器   v1.1.0
Windows 和 macOS 共用此 Chrome 扩展。需要桌面版 Chrome 116 或更新版本。

本次修复：将同一漫画页的图片分块重组为整页

• 对可识别的分页容器（含 SpeedBinb 常见的 content-p 编号页），按分块在整页中的位置合成，保留原始像素尺寸。页面超出屏幕、横向阅读器裁切显示或上下分段加载，不再按当前可见区域截取。
• 缺少分块、位置存在空隙或图片尚未加载时，标记「分块未齐」并拒绝把残页作为完整页导出。让该页完整加载后重新扫描即可更新同一页。
• 新增「手动合并一页的分块」，用于暂时无法自动识别页面边界的网站。
• JPG、PNG、ZIP 和逐张保存继续可用。自动识别有范围限制，特殊阅读器仍可能需要具体适配；导出前请核对整页预览。

从 v1.0 更新（已安装用户）

1. 关闭拾页侧边栏。保留原来加载扩展的 Shiye 文件夹路径，把新 ZIP 内 Shiye 文件夹中的全部文件复制到原文件夹中，替换同名文件，确保包含新文件 layout.js。
2. 打开 chrome://extensions，找到拾页，点「重新加载」图标。确认扩展版本为 1.1.0。
3. 刷新漫画网页，再打开拾页。清空旧列表后，重新收集本章；旧列表中的残页文件不会自动修复，之前下载的文件需要重新导出。
4. 新识别出的分块页会显示「整页 · N 块」。如果仍列出多张横条，使用下面的手动合并。

安装

1. 把整个 ZIP 解压到准备长期保留的位置。Windows 可右键选择「全部解压缩」，macOS 可双击解压。
2. 在 Chrome 地址栏输入 chrome://extensions 并回车。
3. 打开右上方「开发者模式」，点击「加载已解压的扩展程序」。
4. 选择解压后包含 manifest.json 的 Shiye 文件夹。Windows 可能会多解压出一层目录，进入这层目录即可看到 Shiye。
5. 点击 Chrome 工具栏右侧的拼图图标，把「拾页」固定到工具栏。扩展加载后，请保留原文件夹。
   Chrome 官方安装说明见 https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked

收集一章

打开漫画的章节阅读页，点工具栏里的「拾页」。面板会在旁边打开，同一张标签页可以多次追加。

• 一整章在同一网页，且图片都已列出　点击「扫描 / 追加当前页」。
• 向下滚动才显示后续页　点击「滚动收集」。它会从阅读区顶部逐段扫描，在抵达底部后返回原来的位置；虚拟列表中已离开屏幕的分页也会保留。慢速网站若仍有缺页，可把该页滚动到屏幕中，等图片显示后追加。
• 每次点击才翻一页　从章节第一页点击「自动翻页」。它会识别标明“下一页”的控件或页码下拉框。默认最多收集 100 个阅读器页面，计入当前页。在「选择收集方式」中可改为 1 至 500 页。抵达上限、没有明确的下一页、或等不到新图时，面板会说明原因。
• 网站的翻页按钮较特殊　翻一页，点击「扫描 / 追加当前页」，再继续。请使用原来的漫画标签页，以便追加到同一列表。

核对与导出

1. 点击缩略图可放大预览。默认勾选较大的页面图；取消广告、封面或重复页的勾选。可以展开「其他图片」找回未自动勾选的小图。用 ↑ 和 ↓ 调整顺序。
2. 填写章节名称，选择 PNG 或 JPG。PNG 支持透明背景。转成 JPG 时使用白底和 92% 的编码质量。若源图本身已是所选格式，直接保存原文件。实际清晰度取决于网站提供的图源。
3. 选择 ZIP 压缩包或逐张保存，再点「导出」。ZIP 里每张图都是独立文件。逐张保存会在 Chrome 默认下载位置下建立以章节命名的文件夹。文件按勾选顺序命名为 001、002、003……；张数较多时页码自动补齐。
4. 等面板显示「已保存」。ZIP 按约 96 MiB 的图片数据自动分卷，大章节会生成 _01.zip、_02.zip 等独立文件。一张图始终完整保存在同一分卷。Chrome 可能按你的下载设置弹出保存位置对话框。
5. 少数图片失败时，已成功的页面仍会保存。在同一面板点「仅重试失败页」可保留原来的文件编号。ZIP 模式的补图会另存为「章节名_补图.zip」。如果使用了网页的备用图源，导出结果会列出对应页码。

仍然只识别到半页或横条时

1. 先翻到这一页，等待所有分块都显示出来，再点「扫描 / 追加当前页」。显示「分块未齐」时，先补齐缺失分块。
2. 对没有自动合成的分块，点击「全不选」，只勾选同一页的各块。用 ↑ 和 ↓ 调整成图片顺序。
3. 展开「手动合并一页的分块」，上下切分选「从上到下」，左右切分选「从左到右」，点击「合并选中图片为一页」。纵向合并要求各块等宽，横向合并要求等高；不会拉伸图片来凑尺寸。
4. 点击合并后的预览，检查页首、接缝和页尾。选错时点击「撤销上次合并」，再调整；撤销仅保留当前侧边栏会话中的最后一次合并。
5. 确认后选择 JPG 或 PNG 导出。手动合并只处理所选图片，无法自动补回网站尚未加载的内容；请勿把不同漫画页或缺块的一页合在一起。

列表与权限

• 关闭并重新打开侧边栏，可恢复该漫画标签页的列表。关闭漫画标签页或点击「清空」会清除列表。导出期间请保留漫画标签和侧边栏。
• 打开下一章前，先导出，再点两次「清空」，或者用新标签页打开下一章。
• 点击扩展图标后，拾页会读取当前标签页。图片在本机转换和打包；如果图片放在独立图床，导出时 Chrome 可能询问是否允许读取相应域名。可在扩展详情中管理已授予的网站权限。
• 如果状态提示无法读取当前标签页，请回到漫画章节标签，点一次工具栏的拾页图标再扫描。
• 如果阅读器嵌在其他域名的框架里，面板可能会列出框架地址。打开对应地址，在新标签里点拾页。
• 支持常见图片标签、懒加载属性、分辨率候选、单图 CSS 背景、可读取的画布及临时图片，以及可识别分页容器内的多图分块。需要专用客户端、加密拼图或禁止读取图源的阅读器，可能需要针对具体网站适配。单张尺寸超过浏览器画布上限时，原生整图可优先选择源图已有的格式；分块合成超出画布限制时会提示失败。
